How the score is built

Average TF
Add up the skill's TF in all {{ info.M }} {{ words[2] }} (zero where it is absent) and divide by {{ info.M }}. Every {{ words[1] }} counts equally, whatever its size. = {{ '%.4f'|format(info.share) }} ({{ (info.share * 100)|round(2) }}% of a typical {{ words[1] }}'s mentions)
Smoothed IDF
ln((1 + {{ info.M }}) / (1 + {{ info.df }})) + 1, so a skill present everywhere still keeps a weight of 1. = {{ '%.3f'|format(info.idf_smooth) }}
Score
Average TF x smoothed IDF = {{ '%.4f'|format(info.share) }} x {{ '%.3f'|format(info.idf_smooth) }} = {{ '%.4f'|format(info.score) }}
